# M4 盲测报告

**测试方法**：每轮从 PROMPTS.md 随机抽 5 条。每条交给一个全新会话执行，会话只能看 SKILL.md 和 references，按完整流程跑完：新项目 → 场景 → stills 自检 → 代理 → 正式。
**合格标准（SPEC）**：首次 stills 就合格，或经过 1 轮自修合格，算"达标"。5 条里至少 4 条达标，这一轮才算过。
首次 stills 记为第 0 轮，之后"一次只改一个变量"的每次修改记为一轮。

## 趋势

- 第 1 轮平均修 2.8 轮，第 2 轮平均修 1.6 轮。第 1 轮的主要问题（换主体后构图）在第 2 轮已经消失：5 条的取景第一次就对。
- 第 2 轮的失败都很具体，每条一个缺口：玻璃加液体、分屏方向、fur 模板默认值、雪地变体。没有再出现系统性问题。
- 失败原因从"kit 缺能力"变成了"Look 模板本身的默认值 / 特殊变体没覆盖"。

## 回填（kit / 文档改动）

第 1 轮后：
- `useShot({ frame })` / `frameSubject()` 按包围盒自动取景，9:16 自动对准安全区中心。
- PassLabels 自动放在边缘行。
- 台灯配方（`light.md` "实景光源"），锥形光束贴图，阴影近平面随灯距缩放。
- stills 报 NaN 警告并重试；render 报告最后写；超时 120 s。
- 几何 helper：`rod` / `ring` / `torus` / `bentSheet` / `faceZ`。
- jelly 按单词宽度取景；浅色背景要加饱和的说明；小产品 85mm 预设；贴图 repeat 随机位缩放。

第 2 轮后：
- `glassShell()` 加玻璃加液体配方。
- turntable `frontAt` 改成 `frontSec`（按秒算，改片长不跑偏）。
- PassLabels 每个标签整条镜头只选一次行；`rows` 可以部分固定；分屏文档补分割坐标公式和"环绕方向 ↔ 分割线方向"。
- `<Fur wind={{ gust }}>` 加 `gusts()` 阵风包络；球体毛密度公式；压扁球的做法；悬浮时下沉 5–10 mm。
- fur 模板注视点 y 0.065 → 0.075，对焦点移到毛的外表面。
- fur 雪地 / 冬天变体；浅景深地面横线写明是正常现象。
- `scripts/frame.mjs` 从成片抽帧；stills 每次清掉上一轮的帧；doctor 检查中文字体。
- 修 `fmtMs` 的 "27 min 60 s"；冷暖对比规则改为任意两盏灯；焦段优先级（Look > 尺寸表）；允许故意出画；等待渲染时要重复等。

上面的失败原因都已写进 `references/troubleshooting.md`。
