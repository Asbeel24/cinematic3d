# 自检清单

每次跑完 `stills.mjs`：用 Read 打开 `review/contact.png`，看 `review/stats.json`，逐项打勾。
回复里写结论，例如：`曝光 PASS · 对焦 PASS · 几何 PASS · 时间 PASS · 文字 PASS · 规格 PASS`。

## 1. 曝光（看 stats.json）
- [ ] 每帧 `clippedHighlights` < 1%
- [ ] 每帧 `crushedBlacks` < 3%（按 4×4 像素块统计，颗粒不算）
- [ ] `meanLuma`：暗调 0.2–0.4，中调 0.4–0.6，高调 0.6–0.8。和 Look 预期一致
- 注意：stills 打印的 PASS / CHECK 只判断高光和死黑，**平均亮度要你自己对照上面的范围判断**
- 不过：高光多 → 降主光强度或 `film.exposure`；死黑多 → 加 `Bounce` / `SkyFill`，或把背景色调亮

## 2. 对焦
- [ ] 主体清楚，焦平面在主体最该被看的面上（品牌字、杯口、毛尖）
- [ ] 前景虚化是有意的，不是整个画面都糊
- [ ] 文字的每个字母都清楚：转动的产品上，远离镜头那一侧的字母会先虚
- 不过：调 `focus.point`；整片糊 → 光圈从 2.8 改到 4；转动产品上的字一端发虚 → f/4 → f/5.6
- 联系表太小看不清时，Read 全尺寸的 `review/fNNNN.png`

## 3. 几何
- [ ] 没有穿模（物体互相插入、字母重叠）
- [ ] 没有悬空：落在桌面 / 地面上的物体底部 `y = 0`，有接触阴影
- [ ] 没有破面、黑三角、闪烁的 z-fighting（两个面重合）
- [ ] stills 没有打印 `WARNING: geometry produced NaN`
- [ ] 贴花、表盘、标签没有闪烁的碎块（z-fighting）
- 不过：检查 `position.y` 和几何体的原点（底部还是中心）；贴花离开底面 0.2–0.5 mm；NaN 多半是 `Math.pow` / `sqrt` / 除法的参数越界

## 4. 时间
- [ ] 五帧之间运动连贯：没有跳变、没有物体突然出现
- [ ] 首帧不是空画面或全黑（果冻字首帧没有字是允许的，但背景要好看）
- [ ] 尾帧停稳、构图完整
- [ ] 颗粒每帧不同（不"卡住"）；画面整体没有闪烁
- 要看某一段：`stills.mjs --frames 20,25,30,35`
- 时有时无的效果（阵风、落地、闪光）：默认 5 帧多半采不到峰值，用 `--frames` 把峰值帧都采上
- 每次 stills 会清掉 review 里上一轮的 `fNNNN.png`

## 5. 文字
- [ ] 可读：字号够大，和背景有对比
- [ ] 主体和文字在青色安全线以内（9:16：上 8%、下 22%、右 14%）。台子、地面、背景越线没关系
- [ ] 主体从左边缘或其它边**故意出画**（特写里耳机头梁、长物体一端）是允许的，只要主角部分（对焦点、品牌字、脸）在安全区里。不确定时把 `review/fNNNN.png` 全尺寸打开看青线
- [ ] 没有拉伸变形、没有错字
- [ ] 叠层标签（PassLabels、Caption）没有盖住主体

## 6. 规格
- [ ] 画幅、时长、帧率和方案一致（stats.json 的 width / height / fps / durationInFrames）
- [ ] 主体和方案描述一致：颜色、文字、数量

## 7. 风格规则
- [ ] 焦段是 35 / 50 / 85
- [ ] 只有一个主运动
- [ ] 主光有来由，有冷暖对比
- [ ] 运动有缓动，不是线性匀速

自检不过：回到 Shot.tsx，**一次只改一个变量**（一个参数，或一个组件 / 贴图的一处改动），重跑 stills。
第一次 stills 不算，之后最多 4 轮。
