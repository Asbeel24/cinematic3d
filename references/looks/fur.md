# Look：毛发 Fur

一只毛绒耳机放在毛毡上，微风吹动，逆光勾出毛的轮廓，85mm 微距慢慢推近。
参考场景：`src/scenes/fur/FurScene.tsx` → 合成 `look-fur-9x16`。

## 空间
- 毛毡地面 `y = 0`（深灰，噪声凹凸）。
- 耳机：耳罩半径 0.046 m，两耳罩中心 x = ±0.098；头梁是半圆管（半径 0.015 m）；整体绕 y 轴转 -0.62 rad，让右耳罩外侧对着镜头。
- 毛长在：耳罩外侧的穹顶（旋转体）和头梁管上。

## 毛发 `<Fur>`
| 部位 | shells | length | density (u, v) | 其他 |
| --- | --- | --- | --- | --- |
| 耳罩穹顶 | 40 | 0.011 m | [300, 70] | gravity 0.3 |
| 头梁 | 40 | 0.0099 m | [340, 90] | gravity 0.3 |
| 颜色 | 毛尖 `#efe2cf`，根部 `#8a7360` | | | |
| 风 | strength 0.28，dir [1, 0.15, 0.4] | | | |

`density` 按表面实际尺寸给，让毛根间距约 1 mm：管长 0.3 m → u 300 左右；周长 0.09 m → v 90 左右。
旋转体的 UV：u 绕一圈，v 沿轮廓。轮廓点必须**从下往上**（法线朝外），否则毛长进里面。

## 配置对象 `FUR`
| 字段 | 默认 | 可改 | 说明 |
| --- | --- | --- | --- |
| `furColor` / `rootColor` | `#efe2cf` / `#8a7360` | ✓ | 毛尖 / 根部。根部取毛尖的 35–55% 亮度 |
| `feltColor` | `#3a3438` | ✓ | 毛毡 |
| `background` | `#2b262b` | ✓ | 背景 / 雾 |
| `rimTemp` | 5200 | ✓ | 逆光色温 |
| `wind` | 0.28 | ✓ | 风力（毛长的比例），0.1–0.6 |
| `shells` | 40 | ✗ | 32–64；越多越慢（毛发是最慢的 Look） |
| `strand` | 0.011 | ✗ | 毛长 |

## 可调参数
| 说法 | 改动 |
| --- | --- |
| 风再大一点 / 毛动得更明显 | `wind` 0.28 → 0.45 |
| 毛更长更蓬 | `strand` 0.011 → 0.015，同时 `shells` 40 → 48 |
| 轮廓光更亮 | 主光强度 12 → 16 |
| 换粉色 / 换颜色 | `furColor` + `rootColor`（根部同色系压暗） |
| 渲染太慢 | `shells` 40 → 32 |

## 换主体时（毛绒字母、毛绒玩具、毛绒包）
- 任何带 UV 的几何都能长毛：`lathe`、`TubeGeometry`、`TextGeometry`、`SphereGeometry`。
- 毛绒字母：`TextGeometry` 的 UV 不均匀，`density` 按字高给（字高 0.1 m → [100, 100]），倒角要大，否则边缘毛会穿插。
- 毛发物体的底部要贴地；接触处毛会被压，可以把 `gravity` 提到 0.4 让毛下垂盖住接缝。
