# Look：毛发 Fur

一只毛绒耳机放在毛毡上，微风吹动，逆光勾出毛的轮廓，85mm 微距慢慢推近。
参考场景：`src/scenes/fur/FurScene.tsx` → 合成 `look-fur-9x16`。

## 空间
- 毛毡地面 `y = 0`（深灰，噪声凹凸）。
- 耳机：耳罩半径 0.046 m，两耳罩中心 x = ±0.098；头梁是半圆管（半径 0.015 m）；整体绕 y 轴转 -0.62 rad，让右耳罩外侧对着镜头。
- 毛长在：耳罩外侧的穹顶（旋转体）和头梁管上。

## 毛发 `<Fur>`
| 部位 | shells | length | density (u, v) | 其他 |
| --- | --- | --- | --- | --- |
| 耳罩穹顶 | 40 | 0.011 m | [300, 70] | gravity 0.3 |
| 头梁 | 40 | 0.0099 m | [340, 90] | gravity 0.3 |
| 颜色 | 毛尖 `#efe2cf`，根部 `#8a7360` | | | |
| 风 | strength 0.28，dir [1, 0.15, 0.4] | | | |

`density` 按表面实际尺寸给，让毛根间距约 1 mm：管长 0.3 m → u 300 左右；周长 0.09 m → v 90 左右。
旋转体的 UV：u 绕一圈，v 沿轮廓。轮廓点必须**从下往上**（法线朝外），否则毛长进里面。

## 可调参数
| 说法 | 改动 |
| --- | --- |
| 风再大一点 / 毛动得更明显 | `wind` 0.28 → 0.45 |
| 冬天 / 雪地（白地面 + 冷逆光） | 地面 `MeshStandardMaterial` `#e9eef5` 粗糙 0.92 + 噪声凹凸；逆光色温 8000K、反射 5000K、SkyFill 9000/3800；**背景一定要压暗到中灰蓝 `#6c7d94` 左右**，背景太亮逆光勾边就看不见；目标 `meanLuma` 0.7–0.78 |
| 风一阵一阵的 | `wind` 里加 `gust: gusts({ at: [1, 2, 4] })`（见 kit-api → Fur），`strength` 0.4 左右 |
| 毛更长更蓬 | `strand` 0.011 → 0.015，同时 `shells` 40 → 48 |
| 轮廓光更亮 | 主光强度 12 → 16 |
| 换粉色 / 换颜色 | `furColor` + `rootColor`（根部同色系压暗） |
| 渲染太慢 | `shells` 40 → 32 |

## 换主体时（毛绒字母、毛绒玩具、毛绒包）
- 任何带 UV 的几何都能长毛：`lathe`、`TubeGeometry`、`TextGeometry`、`SphereGeometry`。
- `density` 是 UV 两个方向上的毛根数：按表面实际长度算，目标约 1 mm 一根。球（半径 r）：u 方向周长 2πr、v 方向半周长 πr，所以 `[2πr/0.001, πr/0.001]`，r = 3 cm → `[190, 95]`。两极会密一点，看不出来。
- 球正对镜头的部分，毛直指镜头会显得扎（像海胆）：`gravity` 0.35 → 0.55，或 `length` 加长 30%，毛会更趴更软。
- 参考画面 `meanLuma` 约 0.40–0.45（中调偏暗）。
- 景深很浅时，对焦平面和毛毡相交的那一窄条毛毡会是清楚的，看起来像一条横线：**这是正常的**，参考场景里也有，不用修。
- 毛绒字母：`TextGeometry` 的 UV 不均匀，`density` 按字高给（字高 0.1 m → [100, 100]），倒角要大，否则边缘毛会穿插。
- 毛发物体的底部要贴地；接触处毛会被压，可以把 `gravity` 提到 0.4 让毛下垂盖住接缝。逆光下接触处的毛尖会亮成一圈，看起来像浮着：把物体往下**沉 5–10 mm**（陷进毛毡 / 雪里），阴影就接上了。
- 压扁的球（耳罩、毛球垫）：把缩放烘进几何（`geometry.scale(0.72, 1, 1)` 后 `computeVertexNormals()`），不要缩放 group，否则毛长也被压扁。球的两极（毛会聚在一点）朝上下，不要对着镜头。
