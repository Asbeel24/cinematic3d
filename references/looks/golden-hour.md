# Look：黄金时刻 Golden Hour

深圳出租屋窗边，傍晚。桌上黑胶唱机 + 盖碗茶冒热气，百叶窗影子慢慢爬过桌面，光束里有灰尘。
参考场景：`src/scenes/golden-hour/GoldenHour.tsx` → 合成 `look-golden-hour-9x16`。

## 空间
- 桌面 `y = 0`，墙在 `z = -0.48`，窗洞 x ∈ [-0.72, 0.18]、y ∈ [0.24, 1.26]。
- 唱机在 `[-0.17, 0, -0.2]`，盖碗在 `[0.14, 0, 0.28]`（前景、对焦点），唱片封套靠墙。
- 窗外：天空渐变 + 楼房剪影（自发光平面），百叶片间距 0.026 m、倾角 0.62 rad，7 根防盗网竖杆。

| 灯 | 参数 |
| --- | --- |
| 主光 `KeyLight kind="sun"` | 3300K，强度 7，锥角 6.5°，`shadowRadius` 4；距离 9 m，瞄准窗洞中心 |
| 太阳运动 | 方位角 31° → 34.5°，仰角 27° → 26.2°（`animate`，`ease.inOut`）。影子 6 秒爬过约 3.5° |

| 热气 `Steam` | 盖碗口 `[0.155, 0.07, 0.29]`，默认参数 |

## 后期
`background: "#120c08"`，`film: { dof: true, bloom: 0.18, halation: 0.3, grain: 0.35, vignette: 0.28, exposure: 1.0 }`

## 配置对象 `GOLDEN`
| 字段 | 默认 | 可改 | 说明 |
| --- | --- | --- | --- |
| `sunTemp` | 3300 | ✓ | 主光色温。2800 更橙、更晚；4000 更白、接近下午 |
| `sunIntensity` | 7 | ✓ | 5–9 |
| `skyTemp` | 9500 | ✓ | 补光冷度 |
| `haze` | 0.65 | ✓ | 光束浓度 0.3–0.9 |
| `azimuth` | [31, 34.5] | ✓ | 影子爬动的起止。差值越大爬得越快 |
| `elevation` | [27, 26.2] | ✓ | 太阳高度，越低影子越长 |
| `labelColor` | `#d5532a` | ✓ | 唱片标签色 |
| `windowX/Y`、`wallZ` | — | ✗ | 光束、灰尘、gobo 都依赖窗洞位置 |

## 可调参数（用户说法 → 改哪里）
| 说法 | 改动 |
| --- | --- |
| 光再暖 / 更像傍晚 | `sunTemp` 3300 → 3000（每次 -300） |
| 光束更明显 / 更有雾 | `haze` 0.65 → 0.8 |
| 影子爬快一点 | `azimuth[1]` 34.5 → 37 |
| 更暗、更有情绪 | `film.exposure` 1.0 → 0.85；或 `SkyFill` 0.3 → 0.2 |
| 灰尘更多 | `Dust count` 1600 → 2400 |
| 前景虚化更强 | `focus.aperture` 2.8 → 2.0 |
| 换桌上的东西 | 换 `RecordPlayer` / `Gaiwan` 组件，保持在光束照得到的区域（x -0.5–0.2，z -0.3–0.35） |

## 变体：深夜台灯
把窗光换成台灯：见 `references/light.md` 的"实景光源"。保留桌面、`Steam`，删掉 `Beam` 和百叶相关的东西，窗外换夜景（楼房灯光用 `emissive`）。

## 换主体时
- 主体比唱机小（书、眼镜、杯子、相机）时，参考机位会让主体只占画面 10% 左右：用 `useShot({ lens: 35, frame: { center, size, fill: 0.35, elevation: 25 } })` 重新取景，`center` / `size` 取所有桌上物件合起来的包围盒。
- 删掉不用的组件（`RecordPlayer`、`Gaiwan`、`Steam`）时，相关的 import 留着也不影响渲染。
- 新物体放在桌面 `y = 0`，在窗光照到的条带里，否则没有百叶影。
- 有热饮就保留 `Steam`，把 `origin` 移到杯口。
- 前景物体就是对焦点，`focus.point` 跟着移。
