# Look：果冻字 Jelly Type

一个单词的字母逐个掉到粉色无缝背景上，落地压扁、回弹、轻微摇晃后静止。透明果冻材质。
参考场景：`src/scenes/jelly-type/JellyType.tsx` → 合成 `look-jelly-type-9x16`。

## 空间
- 地面 `y = 0`，无缝弯板：地面向后 0.6 m 处以 R = 0.8 m 的圆弧弯起成背景墙。
- 字高 `size` = 0.115 m，深 0.42×size，大倒角（厚 0.16×size，宽 0.075×size，6 段）。
- 字母按字体步进宽度 ×1.18 排开、整体居中；每个字母绕 y 轴扇形微转（-0.06 rad × 偏离中心的序号）。

## 动画（纯函数 `letterPose(t, hit)`）
| 阶段 | 公式 |
| --- | --- |
| 下落 | 落地前 11 帧从 `drop` = 0.9 m 自由落体：`y = drop·(1 − k²)`，拉伸 `sy = 1 + 0.14k²`，`sx = 1/√sy` |
| 落地压扁 + 回弹 | `d` = 落地后帧数：`sy = 1 − squash·e^(−d/6.5)·cos(2πd/9)`，`sx = 1/√sy`（体积守恒） |
| 小跳 | `y = 0.035·e^(−d/5)·max(0, sin(2πd/9))` |
| 摇晃 | `rz = 0.06·e^(−d/6.5)·sin(πd/9)` |
| 时间 | 第 i 个字母落地帧 = `firstHit + i × stagger`（默认 24 + 8i） |
| 动态模糊 | `useMotionBlur(firstHit − 12, 最后落地 + 2, 6)` |

这个 Look **允许超调超过 2%**（squash 0.32）。其他 Look 不行。

## 镜头
| 项 | 值 |
| --- | --- |
| 焦段 | 50mm，低机位（几乎平视） |
| 取景 | **按单词宽度自动算**：`frameSubject` 让落定后的整个单词在 9:16 安全区里（宽度 ≤ 画面 70%），任何长度的词都不会压线 |
| 运动 | 从比落定机位远 14% 的地方 `shot.push` 到落定机位，`ease.inOut` |
| 漂移 | 2 px |
| 景深 | 对焦 `[0, 0.07, 0.03]`，f/2.8 |

## 灯光
冷暖对比来自天光（7800K）和主光（5600K）的差，符合"至少一组差 2000K"。
| 灯 | 参数 |
| --- | --- |
| 主光 `softbox` | 5600K，4.6，`[-0.9, 1.6, 1.2]` → `[0, 0.05, 0]`，锥角 30°，`shadowRadius` 12 |
| 反射 `Bounce floor` | 5200K，0.5，`[0.4, -0.5, 1.5]` |
| 天光 | 7800K / 4800K，0.35 |
| 环境 | 0.6，`rotationY` 1.2（果冻的高光和折射来自这里） |
| 雾 | 地面色，2.4–6 m |

## 材质
`jelly(color, size)`：透射 0.72、IOR 1.38、衰减色 = 字色、衰减距离 0.5×size、清漆 1。

## 后期
`background` = 地面色，`film: { dof: true, bloom: 0.18, halation: 0.12, grain: 0.18, vignette: 0.18, exposure: 0.8 }`。
高调画面要压曝光（0.8），否则粉色背景过曝。

## 配置对象 `JELLY`
| 字段 | 默认 | 可改 | 说明 |
| --- | --- | --- | --- |
| `word` | `"BEAT"` | ✓ | 2–7 个字母。只支持 Fredoka 字体里有的字符（拉丁字母、数字、常用符号），**不支持中文** |
| `colors` | 6 色循环 | ✓ | 每个字母一个颜色 |
| `floor` | `#e7b9a8` | ✓ | 背景 / 地面 / 雾色。ACES + 曝光 0.8 + 雾会把浅色压灰：想要"浅蓝"就给比目标**饱和一档**的颜色（浅蓝用 `#8ccbf2`，不是 `#bfe0f4`） |
| `stagger` | 8 | ✓ | 字母间隔帧数，4–12 |
| `firstHit` | 24 | ✓ | 第一个字母落地帧 |
| `squash` | 0.32 | ✓ | 压扁深度 0.2–0.4 |
| `sound` | true | ✓ | 每个字母落地一声 `pop`（音高逐个升高）。`false` 静音。见 kit-api → sound.tsx |
| `size` / `drop` | 0.115 / 0.9 | ✗ | 机位、灯位按这个尺寸定 |

## 可调参数
| 说法 | 改动 |
| --- | --- |
| 更 Q 弹 | `squash` 0.32 → 0.38 |
| 掉得更快 / 更有节奏 | `stagger` 8 → 6（30fps 下每 0.2 s 一个） |
| 卡音乐节拍 | `stagger` = 帧率 × 60 / BPM（120 BPM、30fps → 15） |
| 背景换颜色 | `floor`（同时影响雾） |
| 字更大 | `Shot` 里 `frameSubject` 的 `fill` 0.11 → 0.14（长单词会被宽度限制自动拦住） |

## 注意
- 取景按单词宽度自动算，长单词会自动拉远，不用手调机位。8 个字母以上字会很小，考虑换 16:9 或拆成两个镜头。
- 中文需要另做 typeface JSON（`scripts/font2typeface.mjs`，字体必须是 OFL 授权），字形多时文件会很大。
