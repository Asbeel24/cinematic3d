# Look：Render Pass

书桌上的采样器 + 磁带机，画面斜向分成"成片 / 白模 / 线框"三条带，分割线缓慢滑动，镜头环绕 20°。
适合"3D 制作过程"、作品集、设计稿展示。
参考场景：`src/scenes/render-pass/RenderPassScene.tsx` → 合成 `look-render-pass-9x16`。

## 空间
- 桌面 `y = 0`（木桌 2.2 × 1.2 m），墙在 `z = -0.55`。桌子和墙标 `userData.noWire`，线框带里只剩产品。
- 采样器在 `[0.06, 0, 0.14]`，转 -0.25 rad；磁带机在 `[-0.04, 0, -0.17]`，转 0.18 rad。

| --- | --- |
| 焦段 | 50mm |

## 分屏
`makeSplitSpec(frames)`：`passes ["beauty","clay","wire"]`，`split "diagonal"`，
分割位置从 `[0.43, 0.6]` 滑到 `[0.37, 0.54]`（`ease.inOut`）。白模色 `#b9b4ab`，线框色 `#bcd8ff`，线框底 `#24324a`。
分割线 1 px 高亮。标签 `<PassLabels>` 走 DOM，自动放在上 / 下边缘行（竖屏 0.12 / 0.74 屏高，横屏和 1:1 0.08 / 0.92），每个标签整条镜头只选一次行，不会中途跳。
想固定某个标签的高度：`rows={[undefined, 0.66, undefined]}`（`undefined` 的仍自动）。

## 可调参数
| 说法 | 改动 |
| --- | --- |
| 白模多一点 | `seamsFrom/To` 第二个值 +0.08 |
| 只要两条带 | `passes: ["beauty", "wire"]`，`seams` 只返回一个值 |
| 竖直分割 | `split: "vertical"` |
| 环绕慢一点 | `orbitDeg` 20 → 12 |
| 线框更亮 | `wireColor` → `#e0eeff` |

## 带的位置（重要）
斜向分屏是从左上到右下：**成片带在左上，白模在中间，线框在右下**。画面里左上的物体只出现在成片里，右下的只出现在线框里。
所以物体要**沿左上 → 右下的对角线排开**，让每条带里都有东西；或者一个大主体压在对角线上，三条带各切到它一部分。
竖直分割（`split: "vertical"`）时就是从左到右。

**分割坐标**：斜向时画面上一点（u 从左 0 到右 1，y 从上 0 到下 1）的分割坐标是 `d = (u·aspect + y) / (aspect + 1)`（9:16 的 aspect = 0.5625）。`seams` 就是这个 d 值。
想让主体被三条带都切到：算出主体在画面里的 d 范围（比如主体中心 d≈0.47），两条分割线放在中心 ±0.06 左右，比如 `[0.41, 0.53]`。

**环绕和分割线方向要一致**：`shot.orbit(+deg)` 会让居中的单个主体在画面里**向右**漂（d 变大）。默认分割线是往左上滑（d 变小，参考场景里物体沿对角线排开所以无所谓）。
**只有一个主体时**，让分割线跟着主体往右下滑：`seamsFrom [0.37, 0.5]` → `seamsTo [0.43, 0.56]`；或者 `orbitDeg` 取负值让主体往左漂、保持默认分割线。

## 换主体时
- 任何产品组合都行；桌面、墙、背景布标 `userData={{ noWire: true }}`。
- `RENDERPASS` 里 `padAccent`、`deckColor` 是采样器 / 磁带机专用的：换主体时删掉，换成新主体自己的字段。
- 物体面数太低时线框很空：用 `roundedBox` 的 `seg` 4 以上、`cylinder` 24 段以上。面数太高（48 段圆柱 + 几十条滚花）线框会糊成一片：圆柱 24–32 段，滚花用贴图不用几何。
- 标签自动放在画面上下边缘，不会压在中间的主体上；用中文标签时字体回退到系统中文字体。
- 用 `useShot({ frame })` 取景时 `elevation` 30 左右（桌面俯拍），`fill` 0.45。
- 屏幕、标签用 `MeshBasicMaterial` + `toneMapped: false`，否则白模带里也会发光不一致。
